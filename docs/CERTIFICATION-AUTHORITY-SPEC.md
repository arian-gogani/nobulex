# Certification Authority Spec

Kova certifies agents like UL certifies electronics. Regulated industries need this.

---

## Model

- **UL model** — Third-party certification for safety/compliance
- **Pricing:** $10K–100K per agent class per year
- **Target:** Finance, healthcare, legal, critical infrastructure

---

## Tiers

| Tier | Scope | Price |
|------|-------|-------|
| **Class certification** | Agent type (e.g., "financial advisor") | $10K–25K/year |
| **Instance certification** | Specific deployed agent | $25K–50K/year |
| **Enterprise** | Org-wide, custom SLAs | $50K–100K/year |

---

## API (Future)

- Submit covenant + evidence bundle
- Certification workflow: review, canary, attestation check
- Issue certificate (signed, content-addressed)
- Renewal: re-verification on model update, annual audit
