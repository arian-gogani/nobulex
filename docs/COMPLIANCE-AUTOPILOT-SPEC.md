# Compliance Autopilot Spec

Continuous compliance monitoring at 0.5–1% of agent operational budget. Salesforce stickiness model.

---

## Model

- **Pricing:** 0.5–1% of agent operational budget
- **Value:** Real-time compliance scores, automatic regulatory reports, pre-violation alerts
- **Stickiness:** Compliance history lives on Kova; churn is costly

---

## Features

| Feature | Description |
|---------|-------------|
| **Real-time score** | Live compliance rate, attestation coverage, breach risk |
| **Regulatory reports** | EU AI Act, NIST, jurisdiction-specific; auto-generated |
| **Pre-violation alerts** | "Action X would violate constraint Y" before execution |
| **Audit trail** | Immutable; export for regulators, courts, insurers |

---

## Stickiness

- Switching = lose compliance history
- New provider = re-establish trust from zero
- Compliance is cumulative; defection is expensive
