# Governance Bootstrap Sequence

Explicit milestones. No permanent central control.

---

## Phase 0 (0–100 agents)

- **Governance:** Kova Labs sets parameters. Centralized.
- **Labeled:** Temporary. Transparent.
- **Scope:** Launch, initial adoption, parameter tuning.

---

## Phase 1 (100–1K agents)

- **Governance:** Advisory council. Diverse stakeholders.
- **Kova Labs:** Retains veto on security-critical changes.
- **Scope:** Broader input; council advises on parameter evolution.

---

## Phase 2 (1K–10K agents)

- **Governance:** Participation-weighted. Stake or usage determines voting power.
- **Kova Labs:** Veto reduces to security-only. Cannot block non-security changes.
- **Scope:** Community-driven parameter updates within safety envelopes.

---

## Phase 3 (10K+ agents)

- **Governance:** Full decentralization. On-chain or federated.
- **Kova Labs:** One participant among many. No special privileges.
- **Scope:** Protocol is community-owned. Kernel remains immutable.
