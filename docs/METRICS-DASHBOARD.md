# Metrics Dashboard

What to track for adoption readiness. The number that matters: **installs**.

---

## Primary Metrics

| Metric | Source | Target |
|--------|--------|--------|
| **npm installs** | npm stats, package download counts | Growth trend |
| **GitHub stars** | GitHub API | Community signal |
| **Website visits** | Analytics | Awareness |
| **DM responses** | Outreach tracking | Champion engagement |

---

## Secondary Metrics

| Metric | Source | Notes |
|--------|--------|------|
| Covenant creations | Telemetry (opt-in) | Usage depth |
| `kova audit` runs | CLI telemetry (opt-in) | Trojan horse adoption |
| MCP servers wrapped | Community reports | MCP wedge |
| GitHub issues/PRs | GitHub | Contributor activity |

---

## Dashboard Structure

1. **Installs** — Weekly npm installs for `kova`, `@nobulex/cli`, `@nobulex/sdk`
2. **Stars** — Repo star count, star velocity
3. **Traffic** — Website unique visitors, doc page views
4. **Outreach** — DMs sent, responses, positive signals
5. **Community** — Contributors, issues, PRs
