# Pricing Strategy

Open core model. Clear free-to-paid transition.

---

## Tiers

| Tier | Price | Includes |
|------|-------|----------|
| **Free (MIT)** | $0 forever | Core protocol (3 primitives), kova CLI, kova audit, self-hosted verification, community support |
| **Kova Pro** | $99/month per org | Hosted verification, dashboard with compliance analytics, EU AI Act report generation, priority support, covenant templates |
| **Kova Enterprise** | $2K–20K/month | Dedicated infrastructure, custom covenant development, insurer-ready compliance packages, SLA guarantees, dedicated support |
| **Kova Certification** | $10K–100K/year per agent class | Third-party certification, Kova Verified badge, ongoing monitoring, insurance-ready documentation |
| **Trust API** | Pay-per-use | $0.001 per verification, volume discounts, real-time trust score queries |

---

## Rationale

- **Free tier** removes adoption barrier. Developers can integrate before committing.
- **Pro** targets teams needing hosted verification and compliance reports.
- **Enterprise** targets regulated industries (finance, healthcare, legal).
- **Certification** maps to REVENUE-MODEL.md (UL model).
- **Trust API** maps to transaction fee (Visa model) at scale.
