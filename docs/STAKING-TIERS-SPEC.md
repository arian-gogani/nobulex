# Productive Staking Tiers Spec

Basic → Verified → Certified → Institutional. Higher stake = verification income + marketplace ranking + governance weight.

---

## Tiers

| Tier | Stake | Benefits |
|------|-------|----------|
| **Basic** | $1 | Protocol access, basic verification |
| **Verified** | $10 | Verification income, marketplace listing |
| **Certified** | $100 | Priority ranking, certification badge |
| **Institutional** | $1,000+ | Governance weight, dedicated support |

---

## Benefits by Tier

- **Verification income** — Two-sided payments; earn when queried (higher tiers earn more)
- **Marketplace ranking** — Trust-gated marketplace; higher stake = better placement
- **Governance weight** — KIP votes, parameter proposals (Institutional)
- **Stake pool** — Pool invested for yield; staking economy

---

## Incentive

- Agents compete to stake more
- Stake = skin in the game = trust signal
- Creates flywheel: more stake → more trust → more queries → more income
