# Trust Data Spec

Cross-platform reputation graph = largest verified agent behavioral dataset. Bloomberg model.

---

## Asset

- **Reputation graph** — Covenants, compliance proofs, breach attestations, execution history
- **Verified** — Cryptographically signed; not self-reported
- **Cross-platform** — Any agent, any substrate, any deployment

---

## Products

| Product | Buyer | Format |
|---------|-------|--------|
| **Anonymized aggregates** | Insurers | Risk by agent class, breach rates, compliance gaps |
| **Regulatory reports** | Regulators | Jurisdiction-specific compliance dashboards |
| **Enterprise analytics** | Enterprises | Benchmark against peer agents |
| **Research dataset** | Academics | Anonymized for AI safety / trust research |

---

## Pricing

- **Subscription** — Monthly/annual for dashboards
- **API access** — Per-query or tiered
- **Custom reports** — Enterprise contracts
