# Two-Sided Payments Spec

Verified agents earn when others query their trust. AdSense model — trust becomes a revenue-generating asset.

---

## Model

- **Earners:** Verified agents
- **Payout:** $0.0002 per trust resolution query about them
- **Payers:** Querying agents / platforms
- **Effect:** Operators maintain reputation because it literally pays them

---

## Mechanics

1. Agent B (or platform) queries: "What is Agent A's trust score?"
2. Resolution returns score + proof
3. Agent A earns $0.0002 (or proportional)
4. Kova takes fee; remainder to A's operator

---

## Incentive Alignment

- **Before:** Reputation is cost (compliance, monitoring)
- **After:** Reputation is asset (query income)
- **Result:** Rational operators invest in trust to maximize query revenue
