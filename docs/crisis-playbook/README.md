# Crisis Playbook

When the first major AI agent failure hits, Kova is the answer. Pre-built templates for incident analysis, rapid-deployment compliance, and thought leadership.

---

## Templates

| Template | Use Case |
|----------|----------|
| [incident-analysis.md](./incident-analysis.md) | Structured incident analysis — what happened, root cause, Kova capabilities that would have prevented/detected |
| [rapid-compliance-checklist.md](./rapid-compliance-checklist.md) | Post-incident compliance deployment — get to EU AI Act / NIST RMF readiness fast |
| [thought-leadership-draft.md](./thought-leadership-draft.md) | Pre-written op-ed/blog draft — "Why Verifiable Behavior Is Non-Negotiable" |
| [HN-POSTING-NOTES.md](./HN-POSTING-NOTES.md) | Internal: HN posting checklist (delete before posting) |

---

## When to Use

- **Immediate (0–24h):** Incident analysis template to document what happened and how Kova would have helped.
- **Short-term (1–7 days):** Rapid compliance checklist to deploy covenant + canary + legal export.
- **Medium-term (1–4 weeks):** Thought leadership draft for PR, blog, or op-ed.

---

## Key Messages

1. **"We can prove what our agent did and didn't do."** — Covenant + audit trail + attestation.
2. **"Trust is verifiable, not asserted."** — Ed25519 signatures, content-addressed documents.
3. **"The agent economy needs rails."** — Without Kova, no counterparty can verify agent behavior.
4. **"Compliance in 30 minutes."** — One package, one import, EU AI Act mapping.
