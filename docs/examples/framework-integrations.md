# Framework Integration Guide

Credit scores for AI agents work with any framework. Install the SDK,
add a few lines to your tool calls, and every action builds a verifiable
track record.

## Install

```bash
pip install nobulex
```

## PydanticAI

Record receipts on tool success and error:

```python
from nobulex import Agent as ReceiptAgent

receipts = ReceiptAgent("my-agent")

@agent.tool
def search(ctx, query: str) -> str:
    try:
        result = do_search(query)
        receipts.act(action_type="tool:search", scope=f"query={query}")
        return result
    except Exception:
        receipts.deny(action_type="tool:search", scope=f"query={query}")
        raise
```

Run the full example: `python examples/pydantic_ai_receipts.py`

## CrewAI

Track receipts per crew member with trust scores:

```python
from nobulex.crewai import NobuCrewTracker

tracker = NobuCrewTracker(crew_id="my-crew")
tracker.on_task_start("researcher", "market_analysis", {"topic": "AI"})
tracker.on_task_complete("researcher", "market_analysis", result="...")

# Failed agent gets lower trust
tracker.on_task_fail("deployer", "push_production", error="Unauthorized")

print(tracker.trust_scores)
# {'researcher': 21.97, 'deployer': 15.77}
```

Run: `python examples/crewai_receipts.py`

## LangChain

```python
from nobulex.langchain import NobuReceipts

tracker = NobuReceipts(agent_id="langchain-agent")
tracker.on_tool_start("search", {"query": "AI agents"})
# On error:
tracker.on_tool_error("web_scrape", error="403 Forbidden")

print(tracker.trust_score)
```

Run: `python examples/langchain_receipts.py`

## Google ADK

Bilateral receipts (tool_call + tool_result) for each action:

```python
from nobulex.integrations.google_adk import NobulexADKCallback

tracker = NobulexADKCallback(agent_id="adk-agent")
tracker.on_tool_start("google_search", {"query": "market data"})
tracker.on_tool_end("google_search", result="47 results")

print(tracker.verify())  # True
```

Run: `python examples/google_adk_receipts.py`

## Haystack

Receipt per pipeline component:

```python
from nobulex.integrations.haystack import NobulexHaystackAudit

audit = NobulexHaystackAudit(agent_id="rag-pipeline")
audit.record_component("text_embedder",
    inputs={"text": "query"},
    outputs={"embedding": [0.1, 0.2]})

print(audit.verify())  # True
```

Run: `python examples/haystack_receipts.py`

## Verify a receipt

Any receipt generated by any framework verifies **offline** — no server,
no network:

```python
assert receipt.verify()   # recomputes action_ref + checks the Ed25519 signature
```

A hosted verification service (paid tiers, trust scores, compliance reports)
is implemented in `packages/verify-api/` but is not yet deployed to nobulex.com.
