# Kova (Deutsch)

**Die Vertrauensebene für die Agentenwirtschaft.**

Kova ist ein offenes kryptografisches Protokoll (MIT-Lizenz), das KI-Agenten ermöglicht, Verhaltensverpflichtungen zu deklarieren, Compliance nachzuweisen und verifizierbare Reputation über Plattformen hinweg aufzubauen. So wie HTTPS den E-Commerce ermöglicht hat, ermöglicht Kova Agenten, sicher über Organisationsgrenzen hinweg zu transagieren.

Ohne Kova können Agenten verschiedener Organisationen die Vertrauenswürdigkeit des anderen nicht verifizieren, keine portable Reputation aufbauen und nicht sicher transagieren. Mit Kova wird eine multi-Billionen-Dollar-autonome Agentenwirtschaft möglich.
