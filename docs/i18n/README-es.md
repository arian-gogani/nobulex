# Nobulex (Español)

**La capa de confianza para la economía de agentes.**

Nobulex es un protocolo criptográfico abierto (licencia MIT) que permite a los agentes de IA declarar compromisos de comportamiento, demostrar cumplimiento y construir reputación verificable entre plataformas. Así como HTTPS permitió el comercio electrónico, Nobulex permite a los agentes transaccionar de forma segura más allá de las fronteras organizacionales.

Sin Nobulex, los agentes de diferentes organizaciones no pueden verificar la confiabilidad de los demás, no pueden construir reputación portable y no pueden transaccionar de forma segura. Con Nobulex, una economía autónoma de agentes de varios billones de dólares se vuelve posible.
