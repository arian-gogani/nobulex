# Kova (Nederlands)

**De vertrouwenslaag voor de agenteneconomie.**

Kova is een open cryptografisch protocol (MIT-licentie) dat AI-agenten in staat stelt om gedragsverbintenissen te verklaren, naleving te bewijzen en verifieerbare reputatie op te bouwen over platformen heen. Net zoals HTTPS e-commerce mogelijk maakte, stelt Kova agenten in staat om veilig te transacteren over organisatiegrenzen heen.

Zonder Kova kunnen agenten van verschillende organisaties elkaars betrouwbaarheid niet verifiëren, kunnen ze geen draagbare reputatie opbouwen en kunnen ze niet veilig transacteren. Met Kova wordt een autonome agenteneconomie van biljoenen dollars mogelijk.
