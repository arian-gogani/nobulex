# Kova (Português)

**A camada de confiança para a economia de agentes.**

Kova é um protocolo criptográfico aberto (licença MIT) que permite que agentes de IA declarem compromissos comportamentais, comprovem conformidade e construam reputação verificável entre plataformas. Assim como HTTPS habilitou o comércio eletrônico, Kova permite que os agentes transacionem com segurança além das fronteiras organizacionais.

Sem Kova, os agentes de organizações diferentes não podem verificar a confiabilidade uns dos outros, não podem construir reputação portátil e não podem transacionar com segurança. Com Kova, uma economia autônoma de agentes de trilhões de dólares se torna possível.
