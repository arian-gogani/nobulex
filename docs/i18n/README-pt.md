# Nobulex (Português)

**A camada de confiança para a economia de agentes.**

Nobulex é um protocolo criptográfico aberto (licença MIT) que permite que agentes de IA declarem compromissos comportamentais, comprovem conformidade e construam reputação verificável entre plataformas. Assim como HTTPS habilitou o comércio eletrônico, Nobulex permite que os agentes transacionem com segurança além das fronteiras organizacionais.

Sem Nobulex, os agentes de organizações diferentes não podem verificar a confiabilidade uns dos outros, não podem construir reputação portátil e não podem transacionar com segurança. Com Nobulex, uma economia autônoma de agentes de trilhões de dólares se torna possível.
