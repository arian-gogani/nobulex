## Draft (Arian's voice)

> "no real audit trail" is the root issue. most agent logging today is
> operator-controlled, which means the operator can modify it after the fact.
> that's not an audit trail, it's a trust-me log.
>
> the fix: cryptographic receipts for every agent action. Ed25519 signed,
> hash-chained. an auditor verifies the chain without trusting whoever
> produced it. change one byte, the signature breaks.
>
> open source, independently verified across multiple implementations.
> github.com/arian-gogani/nobulex
