# @nobulex/antifragile

Antifragile trust mechanisms that strengthen under stress for the Nobulex framework.

## Install

```bash
npm install @nobulex/antifragile
```

## Usage

```typescript
import { antifragile } from "@nobulex/antifragile";

const resilient = antifragile(covenant);
```
