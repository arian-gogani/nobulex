# @nobulex/compliance-autopilot

Automated compliance monitoring and remediation for Nobulex-governed agents.

## Install

```bash
npm install @nobulex/compliance-autopilot
```

## Usage

```typescript
import { ComplianceAutopilot } from "@nobulex/compliance-autopilot";

const autopilot = new ComplianceAutopilot(config);
await autopilot.monitor(agent);
```
