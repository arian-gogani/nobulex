# @nobulex/eu-compliance

EU AI Act compliance checker — fastest path to Aug 2026 compliance for agentic systems.

## Install

```bash
npm install @nobulex/eu-compliance
```

## Usage

```typescript
import { checkCompliance } from "@nobulex/eu-compliance";

const result = await checkCompliance(agentManifest);
console.log(result.compliant); // true | false
```
