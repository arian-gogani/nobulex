# @nobulex/alignment

Alignment verification and monitoring for AI agent behavior within the Nobulex framework.

## Install

```bash
npm install @nobulex/alignment
```

## Usage

```typescript
import { checkAlignment } from "@nobulex/alignment";

const result = await checkAlignment(agent, covenant);
console.log(result.aligned);
```
