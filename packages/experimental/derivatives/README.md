# @nobulex/derivatives

Trust derivatives and covenant-backed financial primitives for the Nobulex framework.

## Install

```bash
npm install @nobulex/derivatives
```

## Usage

```typescript
import { createDerivative } from "@nobulex/derivatives";

const derivative = createDerivative(covenant, terms);
```
