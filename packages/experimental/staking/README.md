# @nobulex/staking

Stake-backed covenant commitments and slashing mechanisms for the Nobulex framework.

## Install

```bash
npm install @nobulex/staking
```

## Usage

```typescript
import { stake, slash } from "@nobulex/staking";

await stake(identity, covenant, { amount: 100 });
```
