# @nobulex/substrate

Substrate/Polkadot integration for anchoring covenants on parachain networks.

## Install

```bash
npm install @nobulex/substrate
```

## Usage

```typescript
import { anchorToSubstrate } from "@nobulex/substrate";

const tx = await anchorToSubstrate(evidenceRoot, provider);
```
