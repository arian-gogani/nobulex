# @nobulex/gametheory

Game-theoretic analysis and incentive design for covenant compliance.

## Install

```bash
npm install @nobulex/gametheory
```

## Usage

```typescript
import { analyzeIncentives } from "@nobulex/gametheory";

const analysis = analyzeIncentives(covenant, participants);
console.log(analysis.nashEquilibrium);
```
