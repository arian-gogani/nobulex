# @nobulex/legal

Legal framework mappings and regulatory compliance utilities for Nobulex covenants.

## Install

```bash
npm install @nobulex/legal
```

## Usage

```typescript
import { mapToRegulation } from "@nobulex/legal";

const mapping = mapToRegulation(covenant, "eu-ai-act");
console.log(mapping.obligations);
```
