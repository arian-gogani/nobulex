# @nobulex/mcp

Model Context Protocol integration for the Nobulex covenant framework.

## Install

```bash
npm install @nobulex/mcp
```

## Usage

```typescript
import { wrapWithCovenant } from "@nobulex/mcp";

const wrapped = wrapWithCovenant(mcpServer, covenant);
```
