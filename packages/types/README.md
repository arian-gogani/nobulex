# @nobulex/types

Shared TypeScript type definitions and protocol schemas for the Nobulex framework.

## Install

```bash
npm install @nobulex/types
```

## Usage

```typescript
import type { Covenant, Identity, EvidenceItem } from "@nobulex/types";

const covenant: Covenant = { /* ... */ };
```
