Quickstart

v1.0.0 live on npm.

Define rules. Enforce before execution. Get a cryptographic receipt for every action. Ten lines of code.

Install:

npm install @nobulex/sdk @nobulex/core

Write a covenant and enforce it:

import { createDID } from '@nobulex/core';
import { createCovenant, enforce, verify } from '@nobulex/sdk';

// 1. Create agent identity
const agent = await createDID('my-agent');

// 2. Define behavioral rules
const covenant = createCovenant({
  name: 'SafeTrader',
  rules: [
    'permit read_portfolio',
    'permit execute_trade where amount <= 10000',
    'forbid execute_trade where amount > 10000',
    'forbid withdraw',
    'require log_all'
  ]
});

// 3. Enforce an action
const result = await enforce(covenant, {
  action: 'execute_trade',
  args: { ticker: 'AAPL', amount: 5000 }
});
// result.allowed = true
// result.receipt = { outcome_hash, chain_hash, signature, ... }

// 4. Anyone can verify independently
const valid = await verify(result.receipt, agent.publicKey);
// valid = true (tamper-evident, offline-verifiable)

That's it. The receipt covers the full action payload (tool name, arguments, result, timestamp). A third party can replay the hash chain and verify independently without accessing your systems.
